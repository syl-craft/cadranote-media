# cadranote-media

Demo clips for [Cadranote](https://github.com/syl-craft/cadranote), kept out of the main repository so its history stays light.

Rendered by `node tools/motion-demo/render.mjs` in the Cadranote repository, which writes straight into `videos/`. Each clip lasts 10 seconds, with captions in English and French: MP4 1920×1080 at 30 fps, GIF 960×540 at 15 fps.
